5. Исправление ошибок в коде
5.1. Исправление капчи (SkiaSharp)
Было:

csharp
canvas.DrawText(_currentCaptchaText, width / 2, height / 2, textPaint);
Стало:

csharp
canvas.DrawText(_currentCaptchaText, x, y, SKTextAlign.Left, font, textPaint);
5.2. Исправление циклических ссылок в JSON
Добавлено в WebApiConfig.cs:

csharp
var jsonSettings = config.Formatters.JsonFormatter.SerializerSettings;
jsonSettings.ReferenceLoopHandling = ReferenceLoopHandling.Ignore;
5.3. Исправление проверки существования пользователя при логине
Было:

csharp
if (user.password_hash != model.password)
Стало:

csharp
string hash = ComputeHash(model.password);
if (user.password_hash != hash)
